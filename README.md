# FingerprintHW

Fphw.js — это легковесная JavaScript-библиотека, предназначенная для генерации уникального "отпечатка" пользователя на основе его IP-адреса и разрешения экрана. Библиотека использует алгоритм хеширования SHA-256 для обеспечения безопасности и конфиденциальности при создании отпечатка.

## Возможности

- **Определение IP-адреса**: Автоматически определяет IP-адрес пользователя с использованием WebRTC или резервных API.
- **Разрешение экрана**: Собирает данные о разрешении экрана пользователя как часть данных для отпечатка.
- **Хеширование SHA-256**: Генерирует безопасный хеш из собранных данных для создания уникального отпечатка.
- **Механизм резервирования**: Обеспечивает надежность, используя несколько методов для получения IP-адреса.

## Установка

Подключите скрипт в вашем HTML-файле:

<script src="https://github.com/Doxinger/fingerprinthw/blob/main/fphw.js"></script>
или минифицированную версию - <script src="https://github.com/Doxinger/fingerprinthw/blob/main/fphwmin.js"></script>
